# 売れているLINEスタンプの分析と、次に作るスタンプの企画（2026年11月）

## 0. 調べ方と注意
- LINE STORE・ユーザーローカル・スタリコのランキングページは、この作業環境のネットワーク制限で直接開けませんでした。
  そのため、検索で拾えた記事・公式資料・ランキング紹介をもとにまとめています。**順位そのものは、
  LINE STOREの「人気クリエイターズ」やユーザーローカルで実際に見て確かめてください。**
- 数字の出どころは末尾の「参考」に書いています。

## 1. 今売れている・使われているスタンプ（見えた範囲）

| 種類 | 例 | ポイント |
|---|---|---|
| 煽り・本音系 | 煽り系の赤ちゃん（2025年 最も使われたスタンプ1位）、「職場の猫は本音を隠せない。」 | 言いにくいことをキャラに言わせる。笑える。 |
| ゆるかわ×あいさつ | ちいかわ「ぺこり」「UN！」、ゆるかわ☆ちび猫、くろ猫 | 毎日使う短い返事。絵が単純で小さくても読める。 |
| ゆる敬語 | 「ぬこさま」ゆる敬語（週間1位の回あり）、「ゆるっと日常敬語」系の新作が多い | 職場・親・ママ友にも使える。購入層が広い。 |
| 犬・猫・柴犬 | 柴犬の動くスタンプ、防災・安否確認や介護連絡に使える柴犬 | 動物は強い定番。**用途をしぼる**と目立つ。 |
| 有名人・アーティスト | モナキ、Mrs. GREEN APPLE など | 個人では真似できないので参考外。 |
| 季節 | ハロウィン・秋、これから年末年始 | 時期の山が大きい。出すタイミングが命。 |

## 2. 売れるスタンプの共通点

1. **文字が大きくて一瞬で読める**（スマホのトーク画面は小さい）。
2. **毎日使う言葉が中心**：おはよう／おやすみ／了解／ありがとう／ごめん／おつかれ。
3. **使う相手がはっきりしている**：家族用・職場用・友だち用・推し活用など。「誰に送るか」が一言で言える。
4. **あるある・本音で笑える**：共感がシェア（＝宣伝）につながる。
5. **動き・BIG・名前入れなどのオプション**：LINEヤフーの資料では、オプションありのスタンプは静止画に比べて
   ダウンロード約1.9倍、利用約3.3倍。8個より16個のほうがダウンロードが多い傾向。
6. **季節イベントに間に合わせる**。

市場は飽和していて、登録クリエイターの9割以上は売上ゼロという話もあります。
「かわいい」だけでなく、**テーマを一つにしぼる**ことが差になります。

## 3. 今のスタンプ（ふくちゃん・ジョン・うに様）との比較

すでに強いところ
- 本物のペット写真で、表情が豊か。写真系は個性が出しやすい。
- 太い手書き風の文字＋白フチで読みやすい。
- うに様の「殿様口調」のようにキャラ設定がはっきりしている。

伸ばせるところ
- 3セットとも「毎日の返事」が中心で、**使う相手（家族・職場など）が同じ**。相手を変えたセットを作ると買う人が増える。
- 静止画のみ。**動くスタンプ**や**名前入れ（カスタム）**はまだない。
- 季節もの（年賀）がない。

## 4. 次に作るスタンプの提案（おすすめ順）

### A. 年末年始・年賀（いちばん急ぎ）
- 2027年は**未（ひつじ）年**。ふくちゃん／ジョン／うに様に、ひつじの角やもこもこ、しめ縄、だるまなどの小物を合わせる。
- 審査と販売開始までに日数がかかるので、**11月中の申請**が目安。
- 16個で十分（あけおめ系8＋冬の日常8など）。
- 文字案：あけましておめでとう／今年もよろしく／ことよろ／謹賀新年／本年もよろしくお願いします／
  メリークリスマス／よいお年を／おせちまだ？／お年玉ちょうだい／寒い…／こたつから出られない／
  初詣いこ／大吉！／今年もお世話になりました／おつかれさま／ゆっくり休んでね

### B. ゆる敬語（職場・親・目上の人向け）
- 同じペット写真で、言葉だけ丁寧にする。「敬語のうに様」は殿様口調との落差も面白い。
- 文字案（40個）：
  おはようございます／おやすみなさい／お疲れさまです／ありがとうございます／承知しました／
  かしこまりました／よろしくお願いします／すみません／申し訳ございません／了解です／
  確認します／少々お待ちください／今向かってます／遅れます…／お先に失礼します／
  お気をつけて／助かりました／さすがです／素敵です／おめでとうございます／
  お大事に／お返事遅くなりました／大丈夫です／お手数おかけします／楽しみです／
  いってきます／ただいま帰りました／おかえりなさい／ごちそうさまでした／いただきます／
  感謝です／なるほどです／いいですね！／考えておきます／また連絡します／
  よろしいでしょうか？／またよろしくお願いします／お疲れさまでした／ほっとしました／がんばります

### C. 本音・あるあるシリーズ
- 「〇〇は本音を隠せない」型。かわいい顔で本音を言わせる。
- 文字案：行けたら行く（行かない）／既読スルーじゃないよ／今起きた／もう無理／帰りたい／
  それな／知らんけど／ちょっと何言ってるかわからない／ねむい／明日から本気出す　など

### D. 家族連絡・実用（犬のジョン向き）
- 「今から帰る」「ごはんいる？」「駅ついた」「買い物ある？」「無事です」「地震大丈夫？」など、
  家族のグループで毎日使う言葉。防災・安否確認の言葉も入れると目的がはっきりする。

### E. オプション付き（中長期）
- うに様の**名前入れ（カスタム）スタンプ**、または**動くスタンプ**（まばたき・しっぽ振り程度でOK）。
- 資料上は静止画より利用が多いので、売れたキャラから順に追加するのがおすすめ。

## 5. 作るときのチェックリスト
- [ ] セット名に「誰向け・何に使う」を入れる（例：「うに様のゆる敬語」「チワックスのジョン 家族連絡」）
- [ ] main画像はいちばんかわいい顔＋一番使う言葉
- [ ] 文字は小さく表示しても読めるか（縮小プレビューで確認）
- [ ] 同じ言葉を他のセットとかぶらせすぎない
- [ ] 季節ものは販売開始日から逆算して申請
- [ ] 出したらSNSやLINE VOOMで紹介する
