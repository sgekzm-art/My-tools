# ふくちゃん本音・あるある　Gemini依頼文（20個ずつ）

ふくちゃんの写真を1〜3枚添付して、前半を送る → 全部できたら新しいチャットで後半を送る。

## 前半（01〜20）

```
添付した犬（ふくちゃん）の写真をもとに、LINEスタンプ用の写真を20枚作ってください。
1枚ずつ別々の画像で、下の01〜20の順番に作ってください。途中で止まったら「続けて」と送るので、続きの番号から作ってください。

【全部の画像で守ること】
・グレーとベージュのもじゃもじゃの毛、立ち耳、ピンクの首輪と骨の形の名札はそのまま。全部同じ犬に見えるように
・本物の写真のような質感、背景は無地の白
・犬の全体がはっきり見えて、耳や足が画面からはみ出さない構図
・表情はわかりやすく少し大げさに
・画像の中に文字・記号・マークは入れない

【ポーズと表情】
01：首を少しかしげて、口が半開き。目がうつろで、よくわかっていない感じのとぼけた表情。上半身のアップ。
02：おすわりして片方の前足を前に上げ、人を指さすようなポーズ。自信満々のドヤ顔。
03：顔を横に向けてそっぽを向いている。目を細めて、まったく興味がなさそうな表情。
04：ふかふかの毛布にすっぽりくるまって、顔だけちょこんと出している。眠そうで動く気ゼロの表情。
05：床に置いたスマートフォンの前で伏せていて、片方の前足が画面の上で止まっている。ギクッとして焦った目。
06：寝起きで頭の毛がボサボサにはねている。目が半分しか開いていない、ぼーっとした顔のアップ。
07：正面をまっすぐ見つめる真顔。眉間にしわを寄せて、理解できないという表情。顔のアップ。
08：伏せてあごを前足の上にのせ、遠くをぼんやり見ている。やる気のない表情。
09：あおむけに寝転がっておなかを見せ、前足をだらんと曲げている。気の抜けたリラックスした顔。
10：口角は上がって笑顔だけど、目が泳いでいて不安そう。無理して笑っている感じ。上半身。
11：玄関のドアの前にちょこんと座って、こちらを振り返っている。さみしそうでうるうるした目。
12：床におなかをべったりつけて手足を伸ばし、溶けたように伏せている。魂が抜けたような無気力な顔。
13：ソファの上で横になってくつろぎ、目を閉じて満足そうな顔。
14：小さなカバンのそばで背筋をピンと伸ばしておすわり。キリッとしたまじめな表情で正面を見る。
15：机のふちにあごをのせて、ぐったりしている。目が半分白目ぎみで、うんざりした表情。
16：地面からジャンプして跳ねている瞬間。口を大きく開けた満面の笑顔で、耳が風になびいている。
17：横向きにばったり倒れて寝転がっている。舌がちょっとだけ出ていて、力尽きた表情。
18：おすわりして胸をはり、あごを少し上げてふんぞり返っている。得意げな顔。
19：毛布に全身すっぽりくるまって、鼻先と目だけがのぞいている。ぬくぬくした表情。
20：丸くなって寝ていて、片方の前足で目元をかくしている。まだ寝ていたい様子。
```

## 後半（21〜40）

```
添付した犬（ふくちゃん）の写真をもとに、LINEスタンプ用の写真を20枚作ってください。
1枚ずつ別々の画像で、下の21〜40の順番に作ってください。途中で止まったら「続けて」と送るので、続きの番号から作ってください。

【全部の画像で守ること】
・グレーとベージュのもじゃもじゃの毛、立ち耳、ピンクの首輪と骨の形の名札はそのまま。全部同じ犬に見えるように
・本物の写真のような質感、背景は無地の白
・犬の全体がはっきり見えて、耳や足が画面からはみ出さない構図
・表情はわかりやすく少し大げさに
・画像の中に文字・記号・マークは入れない

【ポーズと表情】
21：大きなクッションに体がうもれるように寝そべっている。だらけきった幸せそうな顔。
22：体を小さく丸めて、首に毛糸のマフラーを巻いている。寒くてぶるぶるふるえている表情。
23：ぬいぐるみのおもちゃを口にくわえて夢中でかんでいる。真剣な目つき。
24：日の当たる床の上で目を閉じて寝そべっている。気持ちよさそうでおだやかな顔。
25：おすわりして上を見上げている。目がキラキラして、何かをすごく期待している顔。
26：目の前に置かれたおやつを、身を乗り出してじっと見つめている。食べたくてたまらない表情。
27：鼻をくんくんさせながら首を前に伸ばし、身を乗り出している。興味しんしんの顔。
28：空っぽのお皿の前におすわりして、こちらを見上げている。まだもらえると期待している顔。
29：口のまわりに少し食べかすがついている。目だけ横にそらして、とぼけている表情。
30：少し離れた場所で伏せていて、横目でちらっとこちらを見ている。ツンとした表情。
31：おすわりしてプイッと横を向いている。ほっぺをふくらませたような、すねた表情。
32：耳をぺたんと後ろに倒して、目を閉じている。知らんぷりしている表情。
33：少しうつむいて上目づかいで、こちらをじーっと見つめている。何か言いたげな顔。
34：伏せて両方の前足で顔をかくしている。恥ずかしそうな様子。
35：おすわりして頭を前に差し出し、なでてほしそうにしている。しっぽをふっている。うれしそうな顔。
36：少しだけ開いたドアのすきまから、顔を半分だけのぞかせている。じっとこちらを見る目。
37：体は正面を向いたまま固まって、目だけ横にそらしている。気まずそうな表情。
38：後ろ足で立って、前足を胸の前で合わせたお願いポーズ。眉が下がった困り顔。
39：正面からの顔のアップ。まっすぐこちらを見つめる、真剣で誠実な表情。
40：片方の前足を口元に当てて、ひそひそ話をしているようなポーズ。いたずらっぽい表情。
```
