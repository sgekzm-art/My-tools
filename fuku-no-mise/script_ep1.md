# 第1話「ちょっとだけ、座っていいですか」台本 v2

いつも子どもと一緒に食べられるものばかり頼んできたママが、一人の人として食べたいものを食べて、ちょっとだけ一息つく話。魔の2歳児に手を焼く日々は、顔を映さず、後ろ姿・手元・足元で見せる。

**v2 で変えたところ**：ママが癒される場面を足した（カット14〜16）。
- 回想（カット10）の「食べかけのまま冷めたご飯」を、ふくのみせで「最後まで温かいまま食べきる」ことで回収する。
- ちゃこ姉ちゃんの一言「いつも、おつかれさま」でねぎらう。説教はしない。
- 長さは1分ちょうどにこだわらない。実際の音声の長さから、全体は約2分10秒の見込み。
